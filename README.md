# Closet

A private, single-user wardrobe app: photograph what you own, get a clean
illustration of each item, build outfits, and shop for what is missing.

**Status: phase 0.** Nothing is installable yet. This phase tests the risky
parts before the app is built around them: background removal, drawing clothes
from attributes plus the photo, and how accurately Claude tags real photos.

- `bench/` — the phase 0 experiments; see `bench/README.md` to run them.
- `packaging/spike/` — a minimal program proving the heavy dependencies survive
  being packaged into one file; see its README.
- `docs/PHASE0.md` — results so far and what is still open.
- `docs/DECISIONS.md` — what was decided and why.
- `docs/BACKLOG.md` — what is left.

Running the app and setting up phone access will be documented here from
phase 1.
